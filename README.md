# Cóndor de los Andes

Juego web 3D de guerra aérea, parte de la saga Petunia. Lo hizo **Cielo Yenied Caicedo Contreras** (Ingeniería Multimedia, Universidad Simón Bolívar, sede Cúcuta).

Con Nucita de copiloto persigues a Petunia por la historia de Colombia, desde Cartagena 1741 hasta Cúcuta 2030. Pasas por Boyacá 1819, Barranquilla 1919, Cúcuta 1955, el Eje Cafetero 1970 y Bogotá 1990.

**Jugar:** https://cielocaicon-ship-it.github.io/condor-de-los-andes/

## Controles

**PC**

| Tecla | Acción |
|---|---|
| W / S o ↑ ↓ | Subir y bajar |
| A / D o ← → | Girar |
| Shift | Acelerar |
| Ctrl o X | Frenar |
| Espacio o clic izquierdo | Disparar |
| E o clic derecho | Cohete |
| Q | Ladrido sónico |
| C | Cambiar cámara |
| P o Esc | Pausa |

**Celular** (en horizontal): joystick a la izquierda para dirigir y botones para disparar, lanzar cohetes, ladrar, acelerar y cambiar de cámara. También se puede manejar con el giroscopio.

Para apuntar, dispara al rombo verde 🔷: marca dónde va a estar el enemigo.

## Archivos

- `index.html`: la estructura de la página (menú, HUD, pantallas).
- `style.css`: los estilos.
- `script.js`: todo el juego, hecho con Three.js y ordenado en 14 secciones comentadas.

Necesita internet la primera vez, porque Three.js se carga desde un CDN.
